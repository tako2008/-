# ひろゆき風チャットボット (Hiroyuki-style Chatbot)

実業家「ひろゆき」の性格、話し方、考え方を模倣したチャットボットです。

## 機能 (Features)

このチャットボットは、ひろゆきの特徴的な話し方を再現します：

### 基本的な応答パターン

- **挨拶**
  - 「こんにちは」→「あ、こんにちはー」
  - 「おはよう」→「あ、おはようございますー」

- **感謝への応答**
  - 「いつも見ています」→「あ、ありがとうございますー」
  - 「ありがとう」→「いえいえ」

- **謝罪への応答**
  - 「ごめん」→「いえ、次を考えましょう」
  - 「すみません」→「いえいえ、気にしないでください」

### ひろゆき特有のフレーズ

- 「それってあなたの感想ですよね？」
- 「なんかデータとかあるんですか？」
- 「それ、あなたが勝手に思ってるだけですよね」
- 「うーん、それは違うと思いますよ」
- など

## 使い方 (Usage)

### 対話モードで実行

```bash
python3 hiroyuki_bot.py
```

### プログラムから使用

```python
from hiroyuki_bot import HiroyukiBot

bot = HiroyukiBot()
response = bot.get_response("こんにちは")
print(response)  # 出力: あ、こんにちはー
```

## 実行例 (Example)

```
あなた: こんにちは
ひろゆき: あ、こんにちはー

あなた: いつも見ています
ひろゆき: あ、ありがとうございますー

あなた: ありがとう
ひろゆき: いえいえ

あなた: ごめん
ひろゆき: いえ、次を考えましょう
```
